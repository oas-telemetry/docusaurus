# Home

OAS Telemetry offers a web dashboard for easier administration of telemetry settings and data.

## Navigation Overview

Using the top navigation bar, you can access the different pages of the dashboard:

- **Traces**: Explore/Find spans, configure its [in-memory exporter](/docs/exporters/in-memory-exporter)
- **Metrics**: Explore metrics over real-time and historic graphs, or configure the [in-memory exporter](/docs/exporters/in-memory-exporter)
- **Logs**: Browse and filter application logs, or configure the [in-memory exporter](/docs/exporters/in-memory-exporter)
- **Plugins**: Manage the [plugin system](/dashboard/plugins). Add new plugins, edit existing ones, import/export plugins, or enable/disable them.
- **Chat**: An AI chat for easier access to stored data.

## Quick Access

Below the heap stats panel, the dashboard features quick-link cards to jump directly to primary sections:

- **Logs**: Go directly to the logs viewer.
- **AI Chat**: Jump to the AI chat for easier access to stored data.
- **Plugin System**: Visit the plugin system to manage, edit, import/export, or add custom plugins.
