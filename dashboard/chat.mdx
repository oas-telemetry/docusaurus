# Chat

OAS Telemetry provides an AI Chat interface that allows you to **chat with an OpenAI model** that **has access to telemetry data and collection settings for [in-memory exporters](/docs/exporters/in-memory-exporter)**.

For the chat interface to be enabled, you will need to configure an OpenAI API key as an environment variable or as a configuration parameter. Refer to [configuration](/docs/configuration) for more information. You may also change the model used to generate responses.
